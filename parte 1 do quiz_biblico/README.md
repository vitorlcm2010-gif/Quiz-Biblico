Documentação do Quiz Bíblico
Vamos começar com estas informações:
Nome: Quiz Bíblico
Objetivo: Desenvolver um site de perguntas e respostas sobre conhecimentos
bíblicos, permitindo que o usuário teste seus conhecimentos de maneira simples e
interativa.
Funcionamento:
1. O usuário acessa o site.
2. A primeira pergunta aparece automaticamente.
3. O usuário escolhe uma das quatro alternativas.
4. Clica em responder.
5. O sistema informa se a resposta está correta ou incorreta.
6. O usuário avança para a próxima pergunta.
7. Ao terminar, o sistema apresenta a pontuação final.
Limites do projeto:
● Não terá cadastro ou login.
● Não terá menu inicial.
● Não terá ranking.
● Não terá contas de jogadores.
● Terá perguntas com quatro alternativas.
● Terá resultado final com a pontuação.
Requisitos funcionais iniciais:
● 1 — Exibir perguntas bíblicas.
● 2 — Apresentar quatro alternativas.
● 3 — Permitir selecionar uma alternativa.
● 4 — Verifique a resposta selecionada.
● 5 — Informar se a resposta está correta ou incorreta.
● 6 — Avançar para a próxima pergunta.
● 7 — Calcular e exibir a pontuação final.
Requisitos não funcionais iniciais:
● 1 — O site deve ter uma interface simples.
● 2 — O sistema deve funcionar em navegadores modernos.
● 3 — As informações devem ser armazenadas no banco de
dados. ● 4 — O sistema deve apresentar respostas rapidamente.
